# Propuesta de rediseño — Capital Musical

Página interactiva con comparador actual vs. propuesta y prototipo navegable.

## Contenido
- `index.html` — página principal (datos, comparador, cambios con su porqué, prototipo)
- `prototipo.html` — demo navegable (se carga dentro de index.html y también por separado)
- `assets/` — imágenes, fuentes y datos de la página

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube **el contenido** de esta carpeta a la raíz del repositorio (`index.html` debe quedar en la raíz, no dentro de otra carpeta).
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `/ (root)` → Save.
4. En 1–2 minutos el link queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Notas
- GitHub Pages es público aunque el repositorio sea privado: cualquiera con el link puede verlo. La página solo muestra porcentajes (sin ingresos ni ticket promedio) y tiene `noindex`, por lo que no aparece en buscadores.
- Los botones de WhatsApp del prototipo usan el número real del sitio (527771486806). Un clic desde la página pública abre un chat con ese número.
