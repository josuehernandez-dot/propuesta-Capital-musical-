# Capital Musical — Propuesta de mejoras (Equipo WEECOM)

Réplica navegable de capitalmusical.com.mx con 6 mejoras pequeñas. Un interruptor arriba cambia entre **Actual** y **Propuesta**; "Ver cambios" explica cada mejora (qué hay hoy, qué cambia y por qué).

## Qué contiene

```
index.html      la página completa
assets/         estilos, scripts, tipografía e imágenes
README.md       este archivo
```

## Cómo publicarla en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **el contenido** de esta carpeta (no la carpeta en sí): `index.html` y `assets/` deben quedar en la raíz del repositorio.
3. Ve a **Settings → Pages**. En *Build and deployment* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
4. En uno o dos minutos la página queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Para tener en cuenta

- GitHub Pages es **público**: cualquiera con el enlace puede verla. La página lleva `noindex` para que Google no la indexe, y solo muestra porcentajes (sin ingresos ni ticket promedio).
- Los botones de WhatsApp solo muestran un aviso; no enlazan al número real.
- Para ver solo el sitio actual: `?modo=actual`. Para abrir un cambio directo: `?cambio=1` a `?cambio=6`.
- La versión de celular es una referencia: el video de la visita se grabó en escritorio.
